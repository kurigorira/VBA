# 長崎北徳洲会病院 職員名札作成システム セットアップ手順

## ファイル構成

```
名札作成/
  NamudaCreator.bas       ← VBAモジュール本体
  セットアップ手順.md      ← このファイル
  tokushukai_logo.png     ← ★ 徳洲会ロゴ画像（別途用意）
```

---

## 初回セットアップ

### 1. Excelファイルを準備する

1. Excel を起動し、**新規ブック**を作成します。
2. ファイルを **マクロ有効ブック（.xlsm）** として保存します。
   - ファイル名例：`名札作成システム.xlsm`
3. ブックと同じフォルダに `tokushukai_logo.png`（徳洲会ロゴ）を配置します。

### 2. VBAモジュールをインポートする

1. Excel で `Alt + F11` を押して **VBAエディタ** を開きます。
2. メニューバーから **「ファイル」→「ファイルのインポート」** を選択します。
3. `NamudaCreator.bas` を選択してインポートします。
4. VBAエディタを閉じます（`Alt + F4`）。

### 3. ワークブックを初期化する

1. Excel に戻り、`Alt + F8` を押してマクロ一覧を開きます。
2. `ワークブック初期化` を選択して **「実行」** をクリックします。
3. 以下の2枚のシートが自動作成されます：
   - **職員マスター** … 職員情報の入力シート
   - **名札印刷** … 名札レイアウトの出力シート

### 4. ボタンを配置する（推奨）

「職員マスター」シートに以下のボタンを作成すると便利です。

| ボタンのラベル | 割り当てマクロ |
|---|---|
| 選択した職員の名札を作成 | `名札作成_選択職員` |
| 全職員の名札を一括作成 | `名札作成_全職員` |
| 印刷プレビュー | `印刷プレビュー` |

ボタンの追加方法：
1. **「開発」タブ** →「挿入」→「ボタン（フォームコントロール）」
2. シート上でドラッグしてボタンを配置
3. マクロの割り当て画面で上記マクロを選択

## 名札の作成方法

### 通常（1名〜数名）

1. **職員マスター** シートに職員情報を入力します。

   | 列 | 項目 | 入力例 |
   |---|---|---|
   | A | 職員ID | `00123` |
   | B | 氏名（漢字） | `山田 太郎` |
   | C | 苗字ひらがな | `やまだ` |
   | D | 部署名 | `内科病棟` |
   | E | 職種 | `看護師` |
   | F | 役職 | `副師長`（なければ空白） |
   | G | 入職日 | `2026/4/1` |

2. 名札を作成したい行を選択します（複数行選択可）。
3. `名札作成_選択職員` マクロを実行します。
4. **名札印刷** シートで確認・印刷します。

### 4月一括（30名程度）

1. 入職する全職員のデータを職員マスターに入力します。
2. `名札作成_全職員` マクロを実行します。
3. A4用紙に **2列×3行＝6枚/ページ** でレイアウトされます。

## 徳洲会ロゴ画像について

- ブックと同じフォルダに `tokushukai_logo.png` を配置すると、
  フッターエリアにロゴ画像が自動挿入されます。
- 画像ファイルがない場合は、テキストのみで名札が作成されます。

## カスタマイズ

`NamudaCreator.bas` の先頭付近にある定数を変更することで調整できます。

```vba
' 徳洲会カラー（必要に応じてRGB値を変更）
Private Const COL_MAIN As Long = 4423780  ' ヘッダー・枠の色

' 名札のレイアウトサイズ
Private Const BADGE_ROWS As Integer = 22  ' 縦の行数
Private Const BADGE_COLS As Integer = 6   ' 横の列数
Private Const BADGES_PER_ROW As Integer = 2  ' 1ページ横の枚数
```
